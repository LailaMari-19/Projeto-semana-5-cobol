Projeto: Calculadora de Salário em COBOL
Este projeto é uma aplicação desenvolvida em COBOL para o cálculo de bônus salarial com base no tempo de empresa. O programa demonstra os fundamentos da programação estruturada, utilizando parágrafos e a instrução PERFORM para organizar o fluxo de execução.

Regras de Negócio
O sistema recebe os dados de um funcionário e aplica as seguintes regras de bônus:

Até 1 ano de empresa: 5% de bônus.

De 2 a 5 anos de empresa: 10% de bônus.

Acima de 5 anos de empresa: 15% de bônus.

Funcionalidades
Entrada de Dados: Leitura interativa via terminal (Nome, Salário Base e Tempo de Empresa).

Modularização: O código é estruturado em parágrafos lógicos (ENTRADA-DADOS, CALCULA-BONUS, CALCULA-SALARIO, EXIBE-RESULTADO), garantindo a organização e a clareza do fluxo.

Processamento: Implementação de lógica condicional (IF/ELSE) e cálculos aritméticos utilizando o comando COMPUTE.

Como Executar
Utilize um compilador COBOL de sua preferência.

Compile o arquivo calculo-salario.cbl.

Execute o programa e siga as instruções solicitadas no console.

Tecnologia Utilizada
Linguagem: COBOL
